# CViTEK Sensor Support List

## 目录目的

本目录用于生成 **CViTEK 传感器支持列表** PDF 文档。该文档向用户展示 CViTEK 平台支持的传感器型号及其详细技术规格。

文档使用 [Sphinx](https://www.sphinx-doc.org/) 文档生成工具构建，支持生成 PDF 和 HTML 格式的输出。

## 目录结构

```
CViTEK_Sensor_Support_List/
├── README.md                    # 本文件
├── Makefile                     # 构建配置文件
├── logo.png                     # 文档 Logo
├── header_logo.png              # 页眉 Logo
└── source/                      # 源文件目录
    ├── conf.py                  # Sphinx 配置文件
    ├── index.rst                # 文档入口文件
    └── sensor_support_list.rst  # 传感器支持列表表格
```

## 如何添加新的 Sensor

### 1. 编辑传感器列表文件

打开 `source/sensor_support_list.rst` 文件，在表格末尾添加新的传感器条目。

### 2. 表格格式说明

传感器列表使用 RST (reStructuredText) 的 `list-table` 格式，包含以下 12 列：

| 列序号 | 列名 | 说明 | 示例 |
|--------|------|------|------|
| 1 | 制造商 | 传感器制造商名称 | Sony |
| 2 | 型号 | 传感器型号 | IMX135 |
| 3 | 成像区域尺寸 | 传感器成像区域尺寸 | 1/3.06 |
| 4 | 像素尺寸 | 单个像素的尺寸 | 1.12 um |
| 5 | 宽高比 | 图像宽高比 | 4:3 |
| 6 | 分辨率 | 最大分辨率 | `4208*3120(Max Size)` |
| 7 | 接口 | 数据接口类型 | MIPI |
| 8 | 帧率(Fps) | 最大帧率 | `24(In Max Size)` |
| 9 | 输出模式 | 输出模式 | Support WDR |
| 10 | 同步模式 | 同步模式 | - |
| 11 | 封装形式 | 封装形式 | - |
| 12 | 生产状态 | 生产状态（在产/停产等） | 在产 |

### 3. 数据结构说明

传感器列表按照以下层次结构组织：

1. **厂商首行（该厂商第一个Sensor型号的首行）**：每个厂商的第一行，第一列填写厂商名称，同时包含该厂商第一个传感器型号的完整信息
2. **Sensor型号首行**：同一厂商下其他传感器型号的第一行，第一列留空，包含该型号的汇总信息
3. **Sensor型号后续行**：同一传感器型号的其他配置行，包含不同的分辨率、帧率等配置

### 4. 文档添加新厂商

当需要添加一个新的厂商时，**第一行应该同时包含厂商名称和第一个传感器型号的信息**。即，新厂商的第一行既是厂商行，也是第一个传感器型号的首行。

**格式：**
```rst
   * - 厂商名称
     - 第一个传感器型号名称
     - 成像区域尺寸
     - 像素尺寸
     - **宽高比**
     - **分辨率**
     - **接口类型**
     - **帧率**
     - **输出模式**
     - **同步模式**
     - **封装形式**
     - **生产状态**
```

**完整示例：**
```rst
   * - **SmartSense**
     - **SC035HGS**
     - **1/6"**
     - **3.74 um**
     - **4:3**
     - **640*480(Max Size)**
     - **MIPI**
     - **30(In Max Size)**
     - **Linear**
     -
     -
     - **在产**
```

**注意事项：**
- 第一列填写厂商名称
- 第二列填写该厂商的第一个传感器型号名称
- 从"宽高比"列（第5列）到"生产状态"列（第12列）的内容应该加粗显示

### 5. 添加传感器型号首行

**注意**：如果是新厂商的第一个传感器型号，请参考"4. 文档添加新厂商"部分，新厂商的第一行同时包含厂商名称和第一个传感器型号的信息。

对于同一厂商下的其他传感器型号，每个传感器型号的第一行用于显示该型号的汇总信息：

- **第一列**：留空（使用 `-`）
- **第二列**：填写传感器型号名称
- **第三列**：成像区域尺寸
- **第四列**：像素尺寸
- **第五列到第十二列**：从"宽高比"列开始到"生产状态"列，这些列的内容**应该加粗显示**（使用 `**内容**` 格式）

**格式：**
```rst
   * -
     - 传感器型号名称
     - 成像区域尺寸
     - 像素尺寸
     - **宽高比**
     - **分辨率**
     - **接口类型**
     - **帧率**
     - **输出模式**
     - **同步模式**
     - **封装形式**
     - **生产状态**
```

**完整示例：**
```rst
   * -
     - IMX135
     - 1/3.06
     - 1.12 um
     - **4:3**
     - **4208*3120(Max Size)**
     - **MIPI**
     - **24(In Max Size)**
     - **Support WDR**
     -
     -
     - **在产**
```

**注意事项：**
- 首行从"宽高比"列（第5列）到"生产状态"列（第12列）的内容应该加粗
- 如果某个字段为空，使用 `-` 表示

### 6. 添加传感器型号后续行

同一传感器型号可以有多个配置行，用于显示不同的分辨率、帧率等配置：

- **第一列到第四列**：留空（使用 `-`）
- **第五列开始**：填写具体的配置信息（宽高比、分辨率、接口、帧率等）
- **不需要加粗**，使用普通文本格式

**格式：**
```rst
   * -
     -
     -
     -
     - 宽高比
     - 分辨率
     - 接口类型
     - 帧率
     - 输出模式
     - 同步模式
     - 封装形式
     - 生产状态
```

**完整示例：**
```rst
   * -
     -
     -
     -
     - 16:9
     - 3840*2160
     - MIPI
     - 25
     - Linear
     -
     -
     -
```

**说明：**
- 第一行是汇总行，包含传感器型号的汇总信息，从"宽高比"列开始加粗
- 后续行是该传感器的不同配置，第一列到第四列留空，从第五列开始填写配置信息
- 每行数据之间需要有一个空行分隔

### 8. 通用注意事项

- **缩进规则**：
  - 第一列使用 `* -` 标记，缩进为 3 个空格（`   * -`）
  - 后续列使用 `-` 标记，缩进为 5 个空格（`     -`）

- **空行规则**：
  - 每行数据之间必须有一个空行分隔
  - 不同传感器型号之间也需要空行分隔

- **空字段**：
  - 如果某个字段为空，使用 `-` 表示
  - 空字段不需要加粗

- **加粗规则**：
  - 汇总行从"宽高比"列到"生产状态"列应该加粗
  - 后续配置行不需要加粗

## 如何生成 PDF

### 前置要求

确保系统已安装以下工具：
- Python 3
- Sphinx
- XeLaTeX（用于生成 PDF）
- 相关 LaTeX 包

### 生成步骤

1. **进入项目目录**
   ```bash
   cd CViTEK_Sensor_Support_List
   ```

2. **生成 PDF 文档**
   ```bash
   make pdf
   ```

3. **查看生成的 PDF**
   生成的 PDF 文件位于：
   ```
   SensorSupportList/CViTEK_Sensor_Support_List/build/CVITEK_Sensor_Support_List_zh.pdf
   ```

### 其他命令

- **清理构建文件**
  ```bash
  make clean
  ```
  删除 `build/` 目录下的所有生成文件

- **查看帮助**
  ```bash
  make help
  ```

## 文档格式说明

### 特殊格式

- **加粗显示**：使用 `**文本**` 格式
  - 每个传感器型号的第一行从"宽高比"列到最后一列应该使用更大的加粗字体

- **表格宽度**：表格列宽在 `sensor_support_list.rst` 文件的 `:widths:` 参数中定义

### 配置文件

- **conf.py**：Sphinx 配置文件，包含：
  - 项目信息（名称、版本、作者等）
  - LaTeX 输出配置
  - 文档样式设置
  - Logo 和页眉设置

## 常见问题

### Q: 生成 PDF 时出现列数不匹配错误？

A: 确保每行数据都有且仅有 12 列，与表头列数一致。检查是否有遗漏或多余的列。

### Q: 缩进错误？

A: 确保第一列使用 3 个空格缩进（`   * -`），后续列使用 5 个空格缩进（`     -`）。

### Q: 如何修改文档样式？

A: 编辑 `source/conf.py` 文件中的 LaTeX 配置部分，可以修改字体、颜色、页眉页脚等样式。
