## Description ##
run_test.sh is the entry of all middleware test cases.

## Usage ##
1. Download resource. (http://disk-sophgo-vip.quickconnect.cn/sharing/iglxSGiJB)
2. Set mandatory environment variable UT_BIN_DIR.(export UT_BIN_DIR=/mnt/a2/auto_test) or (Modifying the env file)
3. Execute run_test.sh [TEST CASE].
4. TEST-PASS / TEST-FAIL could be found in the output, for judging the test is success or not.
